## Request-proposal page

The seventh page `/design-2/request-proposal` uses the Word document quotation title, description, introduction, fields, and approved options. The original six templates still define the other page layouts; the quotation page extends the existing contact/form layout. Its comparison link points to `/request-proposal`. Six primary header links remain, with the quotation CTA and mobile action exposing this page; the footer lists it. All preview quotation actions now stay in design 2, retaining service query keys. The form preselects one allowed service on initialization (including existing helper aliases); unknown, repeated, or withheld housing keys are ignored. Package query values are not consumed.

The form has explicit Arabic field errors and an alert summary, a labelled multi-service checkbox fieldset, required name/entity/services/quantity/phone, optional timing/email/details, and enforced length limits (200/200/20/254/2000 as appropriate). Quantity is descriptive text for mixed units; Arabic/Persian digits normalize in quantity/phone without losing text. Values remain after handoff; invalid submissions remove a previous handoff link. Submission is disabled until interactive, with a direct WhatsApp link in the sidebar available separately. Valid requests build an encoded message through WebsiteWhatsApp and the existing optional popup helper, always showing a fallback link. No delivery confirmation, response-time promise, backend storage, API, email delivery, publishing integration, or permission change is introduced.

## Motion implementation

Motion references the staggered reveals, tilt, floating badges, and amber pointer highlights at https://basmatyateem.com/. The local `wwwroot/website/design-2/motion.js` module is connected/disconnected by `Design2Layout`; it does not load reference-site scripts or modify the existing website's effects. Explicit `data-d2-motion` attributes identify cards and image frames. The contact form is excluded. CSS motion values live in the preview token block; reveal translation, card tilt, image zoom, and badge floating use separate transform layers.

The comparison bar exposes “إيقاف الحركة” / “تشغيل الحركة” after enhancement succeeds. Its choice uses the design-2-only session storage key `alafkar-design-2-motion-paused`. System reduced motion takes priority, including live changes. Offscreen/hidden-tab hero badges pause. Without JavaScript or IntersectionObserver, content stays visible; keyboard focus reveals pending content immediately. Scoped mutation observation registers filtered project cards, and disposal removes observers, event listeners, animation frames, classes, and temporary styles.
