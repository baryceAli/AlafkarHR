# Communication and Change Management Plan

## Change Objectives

- Help users understand why AlafkarHR is being introduced.
- Reduce go-live confusion through early communication and role-based training.
- Move HR, attendance, leave, and payroll processes to the agreed system of record.

## Audience Messages

| Audience | Key message |
| --- | --- |
| Leadership | AlafkarHR centralizes HR operations, improves control, and enables reporting. |
| HR Team | HR will own employee data, leave setup, lifecycle records, and HR support. |
| Payroll Team | Payroll workflows will depend on approved employee, attendance, leave, and payroll setup. |
| Managers | Managers will review team requests and use system reports for daily decisions. |
| Employees | Employees will use AlafkarHR for attendance and leave self-service where assigned. |
| IT Support | IT will own user access, roles, branch access, and first-line access support. |

## Communication Timeline

| Timing | Communication | Sender |
| --- | --- | --- |
| Project kickoff | Project announcement and objectives. | Executive Sponsor |
| Discovery complete | Confirmed scope and implementation timeline. | HR Sponsor |
| Before UAT | UAT schedule and tester responsibilities. | Implementation Lead |
| Before training | Training schedule and role guide links. | HR Sponsor |
| One week before go-live | Go-live date, support contacts, key changes. | Executive Sponsor |
| Go-live day | System is live, support channel active. | HR/IT |
| Hypercare | Daily known issues and resolutions where needed. | Support Lead |

## Change Risks

| Risk | Mitigation |
| --- | --- |
| Users keep using legacy spreadsheets. | Confirm cutover date and stop legacy process except approved fallback. |
| Managers do not approve requests on time. | Train managers and send go-live reminders. |
| Payroll distrusts output. | Run parallel payroll and reconcile before go-live. |
| Employees do not understand self-service. | Provide short training and simple guide. |
| Access too broad or too narrow. | Run security UAT and branch access checks. |

## Adoption Measures

- Training attendance by role.
- Number of unresolved access issues after go-live.
- Percentage of leave/attendance requests submitted in system.
- Payroll run completion and reconciliation results.
- Support ticket trend during hypercare.
