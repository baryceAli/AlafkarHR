# Post-Go-Live Review

## Review Timing

Conduct the review after the first payroll cycle or two weeks after go-live, whichever is later.

## Review Participants

- Executive Sponsor
- HR Sponsor
- HR Administrator
- Payroll Lead
- Attendance Lead
- IT Lead
- Implementation Lead
- Manager representative
- Employee representative if appropriate

## Review Questions

| Area | Questions |
| --- | --- |
| Adoption | Are users completing attendance, leave, HR, and payroll tasks in AlafkarHR? |
| Data | Are employee, leave, payroll, and organization records accurate? |
| Security | Are roles and branch access working as intended? |
| Payroll | Did the payroll cycle complete accurately and on time? |
| Attendance | Are sessions, exceptions, and reports reliable? |
| Leave | Are balances, applications, and approvals reliable? |
| Support | Are issues resolved within target times? |
| Training | Which roles need extra support? |
