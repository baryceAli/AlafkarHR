# Go-Live Checklist

## Governance

- [ ] Steering committee approves go-live.
- [ ] Open critical/high issues reviewed.
- [ ] Business owners sign UAT.
- [ ] Support and escalation contacts confirmed.

## Configuration

- [ ] Company and main branch configured.
- [ ] Branches, administrations, departments, positions configured.
- [ ] Roles and permissions configured.
- [ ] Branch access assigned where required.
- [ ] General settings reviewed.
- [ ] Currencies configured if payroll/accounting uses them.

## Data

- [ ] Employee data loaded or manually entered.
- [ ] Employee counts reconciled by company, branch, department, status.
- [ ] Leave balances validated.
- [ ] Payroll contracts, structures, loans, and Saudi payroll info validated.
- [ ] Attendance shifts and assignments validated.
- [ ] Attachments/document links validated where in scope.

## Testing

- [ ] SIT complete.
- [ ] UAT complete.
- [ ] Security negative tests complete.
- [ ] Payroll parallel run complete if payroll is in scope.
- [ ] Reports validated by owners.

## Training

- [ ] System administrators trained.
- [ ] HR administrators trained.
- [ ] Payroll officers trained.
- [ ] Attendance officers trained.
- [ ] Managers trained.
- [ ] Employees notified and trained.
- [ ] Role guides distributed.

## Cutover

- [ ] Legacy data freeze announced.
- [ ] Final data load complete.
- [ ] Delta changes applied.
- [ ] Test users replaced or disabled where needed.
- [ ] Production users enabled.
- [ ] Go-live communication sent.

## Hypercare

- [ ] Hypercare channel open.
- [ ] Daily triage schedule agreed.
- [ ] Issue register ready.
- [ ] Support handover date agreed.
