# User Guide: Employee

## Role Purpose

Employees use AlafkarHR for assigned self-service activities such as attendance, leave applications, emergency leave, and viewing permitted personal information.

## Main Pages

- My attendance: `/Attendance/MyAttendance`
- My leave applications: `/LeavesManagement/MyLeaveApplications`
- Emergency leave requests: `/LeavesManagement/EmergencyLeaves`
- Employee public/protected view where enabled by company policy

## Required Permissions

- Attendance self-service permissions approved by the company, such as `Attendance.Attendance.RequestMidDayPermission`.
- Leave request permissions such as `Leave.Leave.RequestEmergencyLeave` and `Leave.Application.Request`.
- View permissions for self-service pages as configured.

## Attendance Workflow

1. Open `/Attendance/MyAttendance`.
2. Review today status.
3. Start attendance session at the beginning of work.
4. Start and end break if break tracking applies.
5. End attendance session at the end of work.
6. If you forgot or were late, submit the approved request type if available.

## Mid-Day Permission Workflow

1. Open the attendance permission request page if available to your role.
2. Create request with date, time, and reason.
3. Submit request.
4. Monitor status until approved or rejected.

## Leave Application Workflow

1. Open `/LeavesManagement/MyLeaveApplications`.
2. Create a new leave application.
3. Select leave type and dates.
4. Add reason and attachment if required.
5. Save and submit.
6. Monitor status.
7. Cancel only when policy allows cancellation.

## Emergency Leave Workflow

1. Open `/LeavesManagement/EmergencyLeaves`.
2. Create emergency leave request.
3. Add attachment if required.
4. Submit request.
5. Follow up with manager/HR if urgent.

## Common Mistakes

| Mistake | Avoidance |
| --- | --- |
| Forgetting to end attendance session. | Check My Attendance before leaving work. |
| Submitting leave without attachment when required. | Prepare attachment before submission. |
| Selecting wrong dates. | Review start/end dates before submit. |
| Re-submitting duplicate requests. | Check existing request status first. |

## Troubleshooting

| Symptom | What to do |
| --- | --- |
| Cannot log in. | Contact IT support. |
| Cannot see attendance or leave page. | Contact HR/IT to verify role. |
| Attendance location is rejected. | Confirm location permission/device rules and contact Attendance Officer. |
| Leave balance looks wrong. | Contact HR Administrator. |

## Escalation

Attendance issues go to Attendance Officer. Leave balance or leave status questions go to HR Administrator. Login and access issues go to IT support.
