# Ember & Flue Chimney Co. — HTML Template (FREE)

A clean, warm, brick-and-soot themed one-page HTML template built for chimney sweep and chimney
repair businesses. Fully static HTML/CSS/JS with a working PHP contact form — no build tools,
frameworks, or dependencies required.

This is the **free, single-page edition** of the template, including the Home page only.


## Features

- **Fully responsive** — looks right from mobile up to desktop
- **Floating "Request Service" button** with a popup contact form
- **Working contact form** (`send.php`) — set your destination email address and go
- **No dependencies** — plain HTML, CSS, and vanilla JavaScript; nothing to install or compile
- **Google Fonts** (Libre Baskerville + Source Sans 3)

## Setting Up the Contact Form

1. Upload the folder (including `send.php`) to any host that supports PHP.
2. Open `send.php` and change the `$TO` value near the top to your own email address.
3. That's it — the floating popup form posts to `send.php` and will email you new enquiries.
